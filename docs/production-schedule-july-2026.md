# July 2026 Production Schedule

Finalized 2026-08-05 in planning session with Claude. Six-day work week, **Sundays off**, max 2 events per day. Not yet entered into the app's planning module.

## Process flow (per batch)

1. **Day 0** — Pull base cider from source tank(s) → **tank-500-1** (mixing tank), add fruit, macerate 2 days
2. **Day 2** — Coarse filter → **tank-500-2**, add sugar, rest 1 day
3. **Day 3** — Fine filter → **brite tank**, carbonate 1 day at **12 psi** · clean 500-1
4. **Day 4** — Keg & bottle · clean 500-2
5. **Day 5** — Clean brite (pairs with next batch's mix-in)

Cleaning rule: every vessel is cleaned the day after it is vacated (slides to Monday if that day is a Sunday).
